# Manuales (Centro de Ayuda)

Poné acá los PDF reales con el mismo nombre de archivo que aparece en
`db/seed_manuales.mjs` (columna `archivo_url`), o cargá tus propios manuales
insertando filas en la tabla `manuales` con la ruta que corresponda.

Ejemplo: si en la DB el `archivo_url` es `/manuales/app-movil-alta-pedido.pdf`,
el archivo tiene que estar en `public/manuales/app-movil-alta-pedido.pdf`.
